# IT Agent (自研资产管理系统) 功能地图

本项目已从“单纯的采集 Agent + 外部 Snipe-IT 同步”定位，升级为**“自研 IT 资产管理系统（Server 端） + 自动化采集器（Agent 端）”**的完整解决方案。

## 📍 阶段一：资产台账底座重构（当前）

- [ ] **多公司组织架构底座**
  - [ ] 引入集团/多公司（Tenant/Company）维度隔离。
  - [ ] 核心实体（资产、人员）挂载公司标识，支持分公司权限与数据隔离。
- [ ] **关系型数据库底座重构**
  - [ ] 引入 PostgreSQL/MySQL 支持。
  - [ ] 构建完整的 CMDB 关系模型（资产表、用户表、部门表、分类表）。
- [ ] **资产全生命周期状态机**
  - [ ] 支持资产独立状态：10-库存, 20-领用, 30-维修, 40-报废。
  - [ ] 支持按生命周期的流转与审计记录（资产时间轴）。
- [ ] **非Agent外设录入与用友U8集成**
  - [ ] 支持非 Agent 设备的批量与手工录入（如显示器、网络设备）。
  - [ ] 支持录入硬件资产关联的 **“用友 U8 采购订单号”**。
- [ ] **UI 资产大盘升级**
  - [ ] 资产列表、详情页、时间轴展示，支持按公司切分视图。

## 📍 阶段二：自动化与组织架构同步

- [ ] **AD 组织架构同步**
  - [ ] 参考 Identity Hub 架构，接入双域 AD 同步员工与组织层级。
- [ ] **人机自动绑定**
  - [ ] 通过 Agent 报送的 `logon_user` 与 AD 账号匹配，自动建议资产与人员的绑定。
- [ ] **数据可视化看板**
  - [ ] 基于新模型的管理大盘与统计报表。

## 📍 阶段三：软件合规与进阶采集

- [ ] **macOS 全量采集与支持**
  - [ ] 补齐 macOS Agent 采集与自动化部署机制。
- [ ] **软件 License 管理与合规审计**
  - [ ] 后台定义受控软件池。
  - [ ] 结合 Agent 采集软件进行盗版/超用识别。
- [ ] **Agent 自动更新与远程任务**
  - [ ] 灰度下发与更新控制，以及基础远程脚本执行。

## 📍 阶段四：安全协同与系统互联

- [ ] **子系统生命周期联动 (System Slot)**
  - [ ] 接入离职、调岗等企业生命周期事件，自动发起资产回收或转移提醒。
- [ ] **USB 管控与安全审计**
  - [ ] 移动介质插拔审计与系统级读写策略下发。
- [ ] **端点网络准入 (NAC) 联动**
  - [ ] 提供设备合规状态 API，供内网安全设备（如深信服）联动判定。
- [ ] **条码/二维码盘点（预留扩展）**
  - [ ] 手机端扫码查阅详情与盘点核对。
