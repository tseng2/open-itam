# IT Agent (自研资产管理系统) 功能地图

本项目已从“单纯的采集 Agent + 外部 Snipe-IT 同步”定位，升级为**“自研 IT 资产管理系统（Server 端） + 自动化采集器（Agent 端）”**的完整解决方案。

## 📍 阶段一：资产台账底座重构（当前）

- [x] **多公司组织架构底座**
  - [x] 引入集团/多公司（Tenant/Company）维度隔离。
  - [x] 核心实体（资产、人员）挂载公司标识，支持分公司权限与数据隔离。
- [x] **关系型数据库底座重构**
  - [x] 引入 PostgreSQL/MySQL 支持（生产已切换 MySQL/MariaDB，GORM AutoMigrate）。
  - [x] 构建完整的 CMDB 关系模型（资产表、用户表、部门表、分类表）。
- [x] **资产全生命周期状态机**
  - [x] 支持资产独立状态：10-库存, 20-领用, 30-维修, 40-报废。
  - [x] 支持按生命周期的流转与审计记录（资产时间轴）。
- [x] **非Agent外设录入与用友U8集成**
  - [x] 支持非 Agent 设备的批量与手工录入（如显示器、网络设备）。
  - [x] 支持录入硬件资产关联的 **“用友 U8 采购订单号”**（仅台账明细字段，不作列表主字段）。
- [x] **UI 资产大盘升级**
  - [x] 资产列表、详情页、时间轴展示，支持按公司切分视图。
- [x] **电脑台账（Excel）全表对齐**
  - [x] 资产主表补齐账面规格字段（CPU/内存/主从硬盘/显卡/网卡MAC），Agent 仅在为空时回填初始化。
  - [x] 资产履历记录表（AssetEvent：处理类型/人员/金额/OA单号/质保/待归还/净值快照）。
  - [x] IT 设备外寄维修登记表（送修/寄回联动资产状态机）。
  - [x] 移动存储领用表、配件记录表（模型与 API 就绪，前端管理页面待补充）。
