# Codebase Memory MCP Skill

This skill provides a helper script to easily index the repository and run queries without manual escaping issues on Windows.

## Usage
Run the python script located in `scripts/index.py` under the skill folder to index the codebase:
```bash
python .zcode/skills/codebase-memory-mcp/scripts/index.py
```
